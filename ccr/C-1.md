  `masked_text_s3` with payee spans replaced by their placeholders and mentioned spans by `[person]`." S5 (Lane B)
  drops the mentioned spans, so S7 (Lane C) cannot find them in the current AgentRequest.
Impact on other lanes: Lane B (S5) fills `req.mentioned_spans` with the mentioned spans it drops. Lane A: the session
  manager initialises it to []. No other lane reads it.
Workaround until approved: src/pipeline/s7-mask.ts reads an optional `mentioned_spans?: Span[]` through a local type
  (`WithMentioned`); when absent, no `[person]` replacement happens. Lane C tests set the field directly.
