GET STARTED

First run

Flex needs one thing from you before it starts: RPC endpoints for the three testnets. Everything else it sets up on its own.

RPC endpoints

For each of Ethereum Sepolia, Base Sepolia and Arbitrum Sepolia, Flex needs two things:

  • a normal RPC URL for reading the chain and sending transactions
  • a list of RPC URLs that support eth_simulateV1, which the wallet uses to check every transaction before you sign. Ideally these are three independent providers, and two of them have to agree.

They all go in ~/.flex/current/.env. The installer already created that file from the template, with a comment above every setting.

The quick way

Put an Alchemy API key and a QuickNode API key in .env as ALCHEMY_API_KEY and QUICKNODE_API_KEY. The QuickNode one is the management key from your account, not a node token. Then let Flex find and test the endpoints: 

cd ~/.flex/current
node scripts/configure-rpc-providers.mjs --third-provider=publicnode

It tries every endpoint, checks that their simulations agree, and writes only the ones that pass into .env. Your other settings stay as they are. PublicNode needs no key.

Start Flex

~/.flex/bin/flexx

On the first run, Flex does the rest of the setup:

  • It opens a page in your browser to connect MetaMask. Flex only needs your public address. No signature or payment is requested.
  • It writes its agent, wallet and CRE configs.
  • It starts Tor and Ollama, and downloads the model (qwen2.5:7b-instruct), which takes a while once.

If a setting is still missing, Flex tells you which ones and the exact file to put them in. After the first run, flexx starts straight into the chat.

Without Tor

Tor is on by default. To connect directly instead, set FLEX_SOCKS_PROXY=direct in .env, then run npm run testnet:setup from ~/.flex/current so the configs pick it up.
