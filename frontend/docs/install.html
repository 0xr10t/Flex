GET STARTED

Installation

One command builds Flex for your user. It takes a minute or two.

What you need

  • macOS or Linux, with Git, Python 3 and npm
  • Node 24, or 22.12 or later on the 22.x line
  • A C/C++ compiler, because the encrypted database is built on your machine. On macOS run xcode-select --install. On Debian or Ubuntu run sudo apt install build-essential.
  • Ollama and Tor (on macOS, brew install tor)
  • MetaMask in your default browser

Install

curl -fsSL https://raw.githubusercontent.com/0xr10t/Flex/master/install.sh | bash

The installer clones the latest Flex into a private folder under ~/.flex. It installs dependencies from the lockfiles, builds the agent and the wallet, and checks that flexx starts. Only then does it switch ~/.flex/current over. If any step fails, nothing is activated and the half-built copy is deleted.

It never uses sudo, never edits your shell files, never starts services and never downloads models. Bash reads the whole script before running any of it, so a dropped connection can't leave you with half an install. If you'd rather read it first, here it is.

Where things go

~/.flex/bin/flexx
The command you run.
~/.flex/current
The active build. Your settings live in .env here and your data in .local.
~/.flex/versions
Each build the installer made.

To type just flexx, add this line to your shell profile:

export PATH="$HOME/.flex/bin:$PATH"

Installing somewhere else

Pass an absolute folder you can write to:

curl -fsSL https://raw.githubusercontent.com/0xr10t/Flex/master/install.sh | bash -s -- --prefix /path/to/flex

Working on Flex itself

For a development checkout instead of an install:

git clone https://github.com/0xr10t/Flex.git && cd Flex
npm ci && npm --prefix wallet ci && npm --prefix wallet/cre/autopay ci
npm run testnet:build
npm link
