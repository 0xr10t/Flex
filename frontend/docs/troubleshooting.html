Troubleshooting

Start with /doctor inside flexx. It checks Node, the config, the agent, the database, the model, Tor and the wallet, and tells you how to fix whatever failed.

The install failed while building

It's almost always the compiler. Install the build tools listed under Installation and run the command again. Nothing was activated, so you're starting clean.

“Flex is already installed here”

The installer never overwrites an install or your settings. To get a newer version, see Updating and removing.

“another install holds .install-lock”

Another install is running, or one was killed partway through. If nothing is running, remove ~/.flex/.install-lock and try again.

“Fill these settings in …/.env”

Flex is missing RPC endpoints. Add the ones it names to that file, or use the quick way on First run, then start flexx again.

Tor or Ollama can't be found

Install them, or point Flex at them: set FLEX_TOR_PATH or FLEX_OLLAMA_PATH in your shell to the program's full path. To skip Tor, see First run.

MetaMask doesn't open

Flex opens your default browser, so that's the one that needs MetaMask. If it says it couldn't open your browser, run flexx from a terminal on your desktop rather than over SSH.

You can also skip the browser step: put your public address in FLEX_WALLET_ADDRESS in ~/.flex/current/.env.
