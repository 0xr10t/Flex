Getting going

What you're installing

Flex lets you type something like send 40 usdc to aradhya on base and turns it into real transactions on Ethereum Sepolia, Base Sepolia and Arbitrum Sepolia. It works out who you mean, which chain your money is on and whether it has to bridge first. Then it shows you a summary. Nothing moves until you say yes, and MetaMask asks you once more before anything is signed.

The model runs locally through Ollama, so your requests, contacts and balances never go to someone else's API. Chain reads, ENS lookups and fetched pages go out through Tor by default.

Before you run the command

  • macOS or Linux, with Git, Python 3 and npm.
  • Node 24, or 22.12 or later on the 22.x line.
  • A C/C++ compiler. The encrypted database is built on your machine. On macOS run xcode-select --install; on Debian or Ubuntu, sudo apt install build-essential.
  • Ollama and Tor. Flex starts both itself when it needs them.
  • MetaMask in your default browser, with some test ETH and test USDC.

What the installer does

It clones the latest Flex into a private folder under ~/.flex, installs dependencies from the lockfiles, builds the agent and the wallet, and checks that flexx starts. Only then does it switch ~/.flex/current over. If any step fails, nothing is activated and the half-built copy is deleted.

It never uses sudo, never edits your shell files, never starts services and never downloads models. The whole script is read before any of it runs, so a dropped connection can't leave you with half an install.

First run

Fill in your settings and let setup write the configs:

cd ~/.flex/current
cp .env.example .env     # your public wallet address and RPC URLs
npm run testnet:setup

Flex only needs your wallet's public address. Leave it blank and setup opens a page in your browser to connect MetaMask instead. Then start it: 

~/.flex/bin/flexx

Add ~/.flex/bin to your PATH and it's just flexx. The first start downloads the model, which takes a while.

Talking to it

send 50 usdc to aradhya on base
what's my balance on arbitrum?
pay mihir 10 usdc every friday for 8 weeks
stop paying mihir

Type / to see the commands and ? for keyboard shortcuts. When you say yes to a summary, the approval page opens and MetaMask pops up for that exact plan.

When something goes wrong

  • Something in Flex isn't working. Run /doctor inside flexx. It checks Node, the config, the model, Tor and the wallet, and tells you how to fix what failed.
  • The build failed. It's almost always the compiler. Install the build tools above and run the command again.
  • Flex is already installed here. The installer won't overwrite an install or your settings. See below to reinstall.
  • another install holds .install-lock. Another install is running, or one was killed. If nothing is running, remove ~/.flex/.install-lock.

Updating and removing

There's no in-place update yet. Your settings live in ~/.flex/current/.env, and your contacts and history in ~/.flex/current/.local. To update, copy both somewhere safe, remove ~/.flex, run the command again, then copy them back.

To uninstall, delete ~/.flex. Flex keeps its database key in your system keychain under the service agent-layer; you can remove that entry too. Nothing else on your system was changed.
